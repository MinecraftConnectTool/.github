# 前言:本组织用于存放MinecraftConnectTool实际工作中的各种服务组件及其服务端,程序本体挂载在MCZLF/MinecraftConnectTool下

## 大家好 👋

  欢迎您看到这里, 这里是 [Loft 团队](https://loft.games "点击前往") 的下属[成员](https://linfon18.loft.games "点击前往Ta的个人主页")开发的独立公益联机软件(这是我们的[官网](https://mct.loft.games "点击前往")). 该项目是一个由 [@linfon18](https://github.com/linfon18 "点击查看") 全权管理的跨平台联机工具, 工作模式包括但不限于 `P2P,Frp`, 运营模式仅包括 `仅接受无条件赞助的公益联机软件`.

本账号用于存储我们在实际开发及运营过程中开发的项目与服务组件, 以便帮助到未来有可能遇到相同问题的小伙伴们.

我们欢迎各位加入我们的讨论以及说出自己的想法

## 🌈 参与指南

### 针对项目

欢迎您针对于项目进行贡献, 您可以自由的选择您感兴趣的项目提交PR请求或者发起一个 Issues , 我们会尽快回复您.

### 针对服务器

我们十分欢迎您对服务器谏言, 您可以前往 [discussions](https://github.com/orgs/MinecraftConnectTool/discussions "点击前往") 发起一个您感兴趣方向的讨论, 我们不会删除您提出的有效问题或是想法, 您可以放心的发表您的想法.
